# Git воркфлоу

## Ветки

- `main` — production код, только через PR
- `develop` — интеграционная ветка
- `feature/*` — новые фичи
- `bugfix/*` — исправления багов
- `hotfix/*` — срочные исправления в main

## Коммиты

Пиши коммиты в формате: `<тип>: <краткое описание>`

### Типы коммитов

- `feat` — новая функциональность
- `fix` — исправление бага
- `docs` — документация
- `style` — форматирование, точка с запятой
- `refactor` — рефакторинг без изменения поведения
- `test` — добавление тестов
- `chore` — обновление зависимостей, настройка

### Примеры

```
feat: добавить вход через Google
```

```
fix: обработал пустой ввод
```

## Pull Request

- Один PR — одна фича или исправление
- Описание: что сделано и зачем
- Прикрепи issue если есть
- Пройди все проверки CI
- Получи минимум одно одобрение
