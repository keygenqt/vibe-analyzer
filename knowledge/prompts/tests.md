# Тестовые вопросы для Vibe Analyzer MCP

## ✅ `list_sources` — список проектов

1. Что у меня есть в базе?
2. Какие проекты проиндексированы?
3. Покажи все доступные проекты
4. Сколько всего проектов в индексе?
5. Дай краткую сводку по всем проектам

## ⚙️ `find_source` — поиск проектов

1. Найди проект vibe-analyzer
2. Покажи информацию о проекте ydx
3. Какие проекты используют лицензию Apache?
4. Найди проекты, связанные с audio
5. Есть ли проект про knowledge base?

## ⚙️ `find_file` — поиск файлов по имени

1. Где лежит главный файл программы?
2. Найди все конфигурационные файлы
3. Покажи файлы с лицензией
4. Есть ли файлы с названием `mod`?
5. Найди все файлы, связанные с тестированием

## ⚙️ `get_stats` — статистика по языкам

1. На каком языке написано больше всего кода?
2. Сколько всего строк в проекте?
3. Какие языки используются, кроме основного?
4. Много ли документации в проекте?
5. Какой процент кода написан не на Rust?

## ⚙️ `get_tree` — структура проекта

1. Покажи, как устроен проект
2. Какие основные директории в корне?
3. Где лежат исходники?
4. Есть ли папка с тестами?
5. Покажи структуру на глубину 1

## ⚙️ `search_ast` — поиск по коду

1. Найди функцию, которая сканирует файлы
2. Где определена структура конфигурации?
3. Покажи все импорты, связанные с OpenSearch
4. Есть ли трейты в проекте?
5. Найди код, отвечающий за индексацию

## ⚙️ `index_source` — индексация

1. Обнови данные по проекту
2. Пересканируй код
3. Добавь новые файлы в индекс
4. Синхронизируй базу с диском
5. Актуализируй информацию

---

## ⚙️ Common — сценарии на пересечение инструментов

1. Найди все Rust файлы и покажи их структуру
2. Сначала узнай, какие проекты есть, потом покажи структуру первого
3. Найди файл с настройками и покажи его содержимое
4. Узнай статистику по проекту, а потом найди самый большой файл
5. Обнови индекс и сразу покажи обновлённую статистику
6. Найди все функции, связанные с MCP, и покажи, в каких файлах они лежат
7. Сначала найди проект по названию, потом покажи его дерево, потом статистику
8. Есть ли в проекте файлы с лицензией MIT? Если да, покажи их
9. Найди главный файл, покажи его структуру (импорты, функции) и статистику проекта
10. Обнови индекс, дождись завершения и покажи, какие файлы изменились
